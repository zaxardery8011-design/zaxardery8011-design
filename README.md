# ZAX-HAN

> **ZAX-HAN builds local-first AI agent tools: a small personal AI brain, LINE AI assistants, and reliability tools that make AI work traceable.**
>
> 我在做一組 local-first 的 AI 工具：小主腦、LINE AI 分身，以及讓 AI 工作可追蹤的可靠性工具。

這裡是我的開源矩陣入口。東西大多還在長，能動的我會標清楚、還在 preview 的也不裝成熟。歡迎順著下面的分區逛。

---

## 🚀 Start here — 從這兩個看起

- **[aiwff-runtime](https://github.com/zaxardery8011-design/aiwff-runtime)** — 個人 AI 小主腦（flagship，preview 中、還在長）：把記憶、規則、調度收在自己機器上跑的 local-first agent runtime。
- **[zax-site](https://github.com/zaxardery8011-design/zax-site)** — 官網與案例入口：想看這一切串起來長什麼樣，從這裡進。

## 🧩 Companion projects — 搭著主腦一起用

- **[line-persona](https://github.com/zaxardery8011-design/line-persona)** — LINE AI 分身框架：把 AI 助理接進 LINE，讓它用你的口徑回應使用者。
- **[dataflywheel](https://github.com/zaxardery8011-design/dataflywheel)** — 把 YouTube 影片蒸餾成可讀 Markdown 報告的資料管線。

## 🛡️ Reliability tools for AI agents — 讓 AI 幹活可信

- **[soplint](https://github.com/zaxardery8011-design/soplint)** — 幫 AI 的作業流程（SOP）做靜態檢查，抓出漏步、矛盾與含糊指令。
- **[execution-proofs](https://github.com/zaxardery8011-design/execution-proofs)** — 讓「AI 說做完了」變成可查的證據，而不是只信它自報。
- **[hyperv-mcp](https://github.com/zaxardery8011-design/hyperv-mcp)** — 用 MCP 把 Hyper-V 虛擬機操作接給 agent，讓自動化跑在受控環境裡。

## 📌 About the pins — 釘選這樣排

上方 Pinned 依這個順序，帶你走一條由裡到外的線：

1. **aiwff-runtime** — 一切的核心：個人 AI 小主腦本體。
2. **soplint** — 先看可靠性工具實際長怎樣，感受一下「讓 AI 可信」是什麼意思。
3. **line-persona** — AI 怎麼走到真實使用者面前（LINE 入口）。
4. **execution-proofs** — 怎麼把 AI 做過的事變成查得到的證據。

## 🧭 The through-line — 一條主線

個人 AI 小主腦（**aiwff-runtime**）→ 走到使用者面前的 LINE 入口（**line-persona**）→ 讓這些 AI 工作變得可追蹤、可信（**soplint** / **execution-proofs**）→ 最後串成官網上的案例。

想看完整的串接與案例，來 **[zax.com.tw](https://zax.com.tw)**。
